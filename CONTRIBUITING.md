# Cómo contribuir

1. Realiza un fork de este repositorio.
2. Clona tu fork.
3. Crea una rama con el formato:
   `pagina-nombre-apellido`
4. Trabaja únicamente dentro de:
   `pages/estudiantes/nombre-apellido/`
5. Realiza al menos un commit descriptivo.
6. Haz push de tu rama.
7. Crea un Pull Request hacia `main`.
8. No modifiques archivos pertenecientes a otros estudiantes.
